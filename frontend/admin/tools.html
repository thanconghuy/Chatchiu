🔄 Đồng Bộ Conversions Thủ Công

ℹ️ Chức năng:
  • Lấy conversions từ AccessTrade API (7 ngày gần nhất)
  • Tự động match với clicks để tìm user
  • Tính cashback (70% commission) và cập nhật balance
  • Lọc trùng theo accesstrade_id
  • Cập nhật status nếu có thay đổi (pending → approved)

⏰ Cập Nhật Trạng Thái Đơn Pending

ℹ️ Chức năng:
  • Quét tất cả đơn hàng đang ở trạng thái Pending
  • Gọi API AccessTrade để lấy status mới nhất (10 requests/phút)
  • Tự động cập nhật status nếu có thay đổi:
    • Pending (0) → Approved (1): Chuyển từ pending_balance sang available_balance
    • Pending (0) → Rejected (2): Xóa khỏi pending_balance
  • Rate limiting tự động (10 requests/1 phút)
  • Mặc định: Cập nhật tối đa 50 đơn cũ hơn 1 ngày

🔄 Đồng Bộ Trạng Thái Đơn Hàng

ℹ️ Chức năng:
  • Đồng bộ trạng thái từ AccessTrade API cho các đơn đã import
  • Cập nhật: status, is_confirmed, confirmed_time
  • Sử dụng khi dữ liệu cũ cần cập nhật trạng thái mới nhất
  • Chỉ cập nhật các trường thay đổi, bỏ qua nếu không có thay đổi
  • Hiển thị chi tiết các thay đổi đã thực hiện
